## 项目介绍

本项目是一个采用前后端分离架构实现的计算器前端。

前端使用原生 HTML、CSS 和 JavaScript 开发，主要负责：

- 接收用户输入的数学表达式；
- 提供数字、运算符及功能按钮；
- 将表达式发送给后端；
- 展示后端返回的计算结果和错误信息；
- 查询并展示计算历史；
- 向后端发送历史记录删除请求。

表达式校验、表达式解析、最终计算和数据持久化均由后端完成，前端不会独立计算最终结果。

## 主要功能

### 1. 基础计算

支持以下内容：

- 加法；
- 减法；
- 乘法；
- 除法；
- 小数；
- 括号；
- 一元正负号；
- 复合表达式。
- 平方；
- 任意幂运算；
- 平方根。

### 2. 计算历史

- 从后端数据库读取计算历史；
- 显示表达式、计算结果和计算时间；
- 按表达式或计算结果搜索历史记录；
- 收藏、取消收藏，并筛选收藏记录；
- 收藏记录自动排列在普通记录之前；
- 一键复制历史记录中的计算结果；
- 为历史记录添加备注，并直接显示在记录中；
- 勾选当前页的多条记录后批量删除；
- 删除指定计算记录；
- 一次清空全部历史记录；
- 历史记录分页浏览；
- 删除成功后重新加载最新历史记录。

### 3. 异常提示

前端可以展示以下错误信息：

- 表达式为空；
- 表达式格式错误；
- 除数为零；
- 无法连接后端；
- 历史记录读取失败；
- 历史记录删除失败。

## 前后端交互

开发环境的后端地址默认为：

```text
http://127.0.0.1:8000
```

前端使用以下接口：

| 请求方法 | 接口地址 | 功能 |
| --- | --- | --- |
| POST | `/api/calculate` | 计算表达式并保存记录 |
| GET | `/api/history` | 获取计算历史 |
| GET | `/api/history?page=1&page_size=10` | 分页获取历史记录 |
| GET | `/api/history?keyword=...` | 搜索计算历史 |
| GET | `/api/history?favorite_only=true` | 获取收藏记录 |
| PATCH | `/api/history/{id}/favorite` | 收藏或取消收藏 |
| PATCH | `/api/history/{id}/metadata` | 修改记录的备注 |
| DELETE | `/api/history/batch` | 批量删除选中的历史记录 |
| DELETE | `/api/history/{id}` | 删除指定历史记录 |
| DELETE | `/api/history` | 清空全部历史记录 |

计算请求示例：

```json
{
  "expression": "(1+2)*3"
}
```

成功响应示例：

```json
{
  "success": true,
  "expression": "(1+2)*3",
  "result": 9
}
```

如果后端部署地址发生变化，需要修改 `js/api.js` 中的 API 基础地址。

## 本地运行方法

### 1. 启动后端

按照后端仓库中的 `README.md` 安装后端依赖并启动服务。

后端默认运行地址：

```text
http://127.0.0.1:8000
```

可以访问以下地址检查后端是否正常运行：

```text
http://127.0.0.1:8000/api/health
```

### 2. 启动前端

1. 使用 Visual Studio Code 打开本项目目录；
2. 安装 Live Server 扩展；
3. 右键单击 `index.html`；
4. 选择 `Open with Live Server`；
5. 在浏览器中访问页面。

Live Server 的默认地址通常为：

```text
http://127.0.0.1:5500
```

本项目没有第三方前端依赖，因此不需要执行 `npm install`。

## 使用方法

1. 使用计算器按钮输入数学表达式；
2. 单击等号按钮；
3. 前端将原始表达式发送给后端；
4. 后端校验并计算表达式；
5. 后端保存成功的计算记录并返回结果；
6. 前端展示计算结果并刷新历史记录；
7. 可以通过历史记录旁的删除按钮删除指定记录。

## 前后端分离说明

项目的处理流程如下：

```text
用户输入表达式
→ 前端发送原始表达式
→ 后端校验并解析表达式
→ 后端计算结果
→ 后端保存计算记录
→ 后端返回结果
→ 前端展示结果
```

停止后端服务后，前端仍然可以显示页面并接收按钮输入，但不能独立产生新的有效计算结果。

## 注意事项

新增功能：`x²` 对当前表达式平方，`xʸ` 输入幂符号，`√x` 对当前表达式开平方根。全部由后端计算。

历史每页显示 10 条，使用 `Previous` 和 `Next` 翻页。搜索或更改收藏筛选时会返回第一页。`Clear All` 会删除全部记录（包括收藏），并要求确认。

- 建议使用 Live Server 运行页面，不要直接双击 `index.html`；
- 使用前应先确认后端服务已经启动；
- 前端不得使用 `eval()` 计算表达式；
- 前端不得先计算结果，再将结果交给后端保存；
- 部署后应修改正式 API 地址及后端 CORS 白名单；
- 提交作业前需要填写姓名、学号、GitHub 仓库链接和部署地址。
